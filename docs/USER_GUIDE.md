## 0. 시작하기
1. 브라우저에서 `http://<서버 주소>:8889` 접속
2. **회원가입** 탭에서 username(영문/숫자 3자 이상)과 password(8자 이상)로 가입, 가입하면 바로 로그인됨
3. 상단 메뉴에서 기능 선택: **예측 / Agent / Custom 학습 / 기록**, ADMIN 계정이면 **Admin**도 보임

## 1. 기능별 사용법

### 1.1 예측
- 상단 **예측** 메뉴
- 순서
  1. property 카드 선택: **FreeSolv(수화 자유에너지) / ESOL(수용해도) / Lipo(친유성) / ClinTox(임상 독성)**
  2. SMILES 입력 (한 줄에 하나, 최대 100개)
  3. **예측 실행**
- Custom 모델로 예측하려면 아래 "Custom 모델 사용" 목록에서 선택함
  - 목록에는 내 모델(READY/SERVING)과 Admin이 승인한 공개 모델이 나옴
- 결과 화면
  - 회귀: 예측 값과 단위, Model 1~5 평균, 모델 간 표준편차, 값 해석 설명
  - 분류(ClinTox): 항목별 확률, 판정(예: "1 · FDA 승인 약물"), 판정 기준 0.5
  - "모델별 결과 · 재현 정보"를 펼치면 Model 1~5 각각의 값과 모델 버전, descriptor 방식, 분할 방식, representation을 볼 수 있음
- RDKit이 해석하지 못하는 SMILES는 그 행만 실패로 표시되고 나머지는 정상 예측됨

### 1.2 Agent
- 상단 **Agent** 메뉴, 자연어로 질문하면 답변함 (예: "아스피린 CC(=O)Oc1ccccc1C(=O)O 수용해도 예측해줘")
- 예측 값은 Agent가 만들지 않음, 항상 서비스의 예측 모델(Model 1~5)을 tool로 호출한 결과를 설명함
- SMILES나 property가 빠져 있으면 먼저 되물음
- 답변은 Markdown(굵은 글씨, 목록, 표)으로 표시됨
- tool 호출과 결과는 회색 상자로 표시되고, "상세"를 펼치면 원본 결과를 볼 수 있음
- 왼쪽 목록에서 이전 대화를 다시 열 수 있음
- `.env`에 `OPENAI_API_KEY`가 없으면 "OPENAI_API_KEY가 설정되지 않았습니다" 안내가 나옴

### 1.3 Custom 학습
- 상단 **Custom 학습** 메뉴, 내 CSV 데이터로 ChemPrompt 모델(Model 1~5)을 학습함

#### CSV 준비
- 필수 열 2개: **SMILES 열**(분자 구조) + **Target 열**(예측할 숫자 값)
- 다른 열(ID, 이름 등)은 있어도 됨, 학습에는 쓰지 않음
- 최소 25행 이상, 파일 크기 50MB 이하
- 분류 데이터는 target이 0/1이어야 하고, 각 클래스가 5개 이상이어야 함
- 예시 파일: `sample/hppb.csv` (HPPB, 혈장 단백질 결합률 %, 1,614개 분자, SMILES 열 이름은 `smile`)

#### 학습 순서 (10단계)
| 단계 | 하는 일 | 입력 |
|---|---|---|
| 1. Dataset Upload | CSV 업로드 | 이름, 파일 |
| 2. Column Mapping | SMILES 열과 Target 열을 하나씩 선택 | 자동 추천됨, 열 미리보기 제공 |
| 3. Validation | 결측·숫자 아닌 target·잘못된 SMILES 행 제거, 학습 가능 여부 확인 | 없음 |
| 4. Task Configuration | 회귀/분류 선택, 모델 이름 | 데이터에서 추론한 값이 기본 |
| 5. Descriptor Mode | FULL / FEATURE_SELECTION / GENETIC | 선택 |
| 6. Split Strategy | RANDOM(무작위) / SCAFFOLD(분자 골격 기준) | 선택하면 학습 자동 시작 |
| 7~10. 자동 | representation 생성 → Model 1~5 학습 → 평가 → 모델 등록 | 진행 상황이 실시간 표시됨 |

- 2단계에서 SMILES가 아닌 열(예: ID 열)을 고르면 바로 안내 메시지가 나오고 다음으로 넘어가지 않음
- 단계는 순서대로만 진행되고 앞 단계로 되돌아갈 수 없음, 잘못 진행했으면 workflow를 삭제하고 새로 시작함
- 학습이 끝나면 "모델별 검증 결과" 표가 나오고, 모델은 READY 상태로 **내 모델** 목록에 등록됨
- READY 모델은 본인이 바로 예측에 쓸 수 있음, 다른 사용자에게 공개하려면 Admin 승인이 필요함

#### 학습 중단과 삭제
- **학습 중단**: 진행 중인 workflow 상세 화면의 "학습 중단" 또는 목록의 "중단"
  - 진행 중인 단계가 끝나는 시점(단계 사이, embedding 묶음 사이)에 멈춤, 보통 몇 초 안에 멈춤
  - 중단된 workflow는 CANCELLED 상태가 되고 이어서 진행할 수 없음
- **Workflow 삭제**: 진행 중이 아닌 workflow의 "Workflow 삭제" / "삭제"
  - 함께 지워지는 것: workflow 기록, 학습 기록, 그 workflow에 올린 데이터셋, embedding 캐시
  - 학습으로 만든 모델이 있으면 버튼 3개 중에서 고름
    - **취소**: 아무것도 지우지 않음 (Esc, 창 바깥 클릭도 같음)
    - **Workflow만 삭제 (모델 유지)**: 모델은 남아서 예측에 계속 쓸 수 있음
    - **모델까지 모두 삭제**: 모델과 그 모델로 한 예측 기록까지 삭제
  - 학습 중인 workflow는 삭제할 수 없음, 먼저 중단해야 함
- **내 모델 삭제**: "내 모델" 목록의 "삭제"
  - 모델 파일과 그 모델로 한 예측 기록이 함께 지워짐
  - Admin이 승인한(SERVING) 모델은 삭제할 수 없음, Admin에게 Archive를 요청함
- 삭제는 되돌릴 수 없음

### 1.4 기록
- 상단 **기록** 메뉴, 내 예측 기록 목록 (최근 100건)
- 행을 클릭하면 아래에 결과 상세(모델별 결과, 재현 정보)가 나옴
- 경로 열의 WEB은 예측 화면, AGENT는 Agent 대화에서 한 예측임

### 1.5 Admin (운영자)
- ADMIN 계정으로 로그인하면 상단 메뉴에 **Admin** 탭이 생김 (`http://<서버 주소>:8889/#/admin`)
- 일반 사용자에게는 탭이 보이지 않고, 주소를 직접 입력해도 서버가 막음(403)
- 화면 구성과 할 수 있는 일
  | 영역 | 할 수 있는 일 |
  |---|---|
  | Representation | 현재 embedding 방식(mock / Aya)과 Aya 서비스 상태 확인 |
  | 현황 | 모델 상태별 개수, 사용자 수, 학습 작업 수 |
  | Model versions | 모든 모델(built-in + 사용자) 목록, **검증**, **승인·Serving**, **Archive**, **상세**(metadata, 파일 목록, seed 등) |
  | 모델 패키지 업로드 | 외부에서 학습한 모델 zip 업로드 → 자동 검증 |
  | Built-in 데이터 · 학습 | built-in property의 데이터 버전 등록, descriptor mode / split을 골라 5-fold 학습 시작 |
  | Training jobs | 모든 학습 작업 목록, 진행 중인 작업 **중단** |
  | Users | 가입한 사용자 목록 |
- `127.0.0.1:8100`은 운영자 화면이 아니라 Aya representation 서비스(화면 없는 내부 API)임

## 2. 결과 해석

### Property 이름과 단위
| 코드 | 국문 이름 | 단위 | 해석 |
|---|---|---|---|
| FreeSolv | 수화 자유에너지 | kcal/mol | 음수일수록 물과 잘 어울림(친수성), 양수일수록 물을 싫어함(소수성), MoleculeNet 원본 `SAMPL.csv` 실험값 사용 (예: 에탄올 −5.0) |
| ESOL | 수용해도 | log(mol/L) | 클수록 물에 잘 녹음 (0 = 1 mol/L, −2 = 0.01 mol/L) |
| Lipo | 친유성 (지질 분배계수) | logD | pH 7.4 옥탄올/물 분배계수, 클수록 지방(세포막) 쪽으로 잘 분배됨 |
| ClinTox | 임상 독성 | 확률 (0~1) | 아래 두 항목을 각각 예/아니오로 분류 |

| ClinTox 항목 | 국문 이름 | 1이면 | 0이면 |
|---|---|---|---|
| FDA_APPROVED | FDA 승인 여부 | 미국 FDA 승인 약물 | 미승인 |
| CT_TOX | 임상시험 독성 | 독성 때문에 임상시험에서 실패 | 독성으로 인한 실패 없음 |

### 예측 값 읽는 법
- 예측 값은 Model 1~5의 평균임
- **모델 간 표준편차**: 5개 모델의 예측이 얼마나 갈리는지 보여 주는 참고치, 클수록 예측이 불확실함
- 분류는 Model 1~5 확률의 평균이며, 0.5 이상이면 1로 판정함
- 예측 값과 오차(RMSE)는 모두 **target의 원래 단위**임
- 학습 데이터와 많이 다른 분자는 범위 밖 값이 나올 수 있음 (예: 결합률 %인데 음수), 연구 참고용이며 실험 검증을 대체하지 않음

### 검증 성능이란
- 학습에 쓰지 않은 데이터로 모델을 시험한 점수임
- 각 Model(1~5)은 데이터의 약 80%로 학습하고, 학습 때 보지 못한 나머지 20%로 예측해서 실제 값과 비교함
- Model 1~5는 서로 다른 20%로 시험하고, 화면의 값은 5개 결과의 평균 ± 표준편차임
- "처음 보는 분자를 넣었을 때 이 정도로 맞힌다"는 기대치로 보면 됨

| 지표 | 쓰는 곳 | 의미 | 좋은 값 |
|---|---|---|---|
| RMSE | 회귀 | 예측과 실제 값의 평균적인 오차 크기 (원래 단위) | 작을수록 좋음 |
| R² (결정계수) | 회귀 | 실제 값의 차이를 예측이 얼마나 설명하는지 | 1에 가까울수록 좋음, 0이면 평균값으로 찍는 수준 |
| Pearson | 회귀 | 예측과 실제 값이 직선적으로 함께 움직이는 정도 | 1에 가까울수록 좋음 |
| Spearman | 회귀 | 분자들의 순위(어느 쪽이 더 큰지)를 맞히는 정도 | 1에 가까울수록 좋음 |
| ROC-AUC | 분류 | 1인 분자와 0인 분자를 구분하는 능력 | 1에 가까울수록 좋음, 0.5면 무작위 수준 |
| F1 / Accuracy | 분류 | 판정(0/1)이 맞은 정도 | 1에 가까울수록 좋음 |

- 개발용 설정(`REPRESENTATION_MODE=mock`)으로 학습한 모델의 성능 값은 실제 ChemPrompt(Aya) 성능을 나타내지 않음, 실제 성능은 Aya 모드로 학습해야 확인할 수 있음

## 3. 자주 묻는 질문

| 증상 / 질문 | 원인과 해결 |
|---|---|
| 운영자 화면은 어디? | 같은 홈페이지에서 ADMIN 계정으로 로그인 → 상단 **Admin** 탭 |
| Custom 학습 2단계에서 "SMILES가 아닌 것 같습니다" | SMILES가 아닌 열을 고른 것임, 열 미리보기에서 "SMILES로 보임" 표시가 있는 열을 고름 |
| Custom 학습을 잘못 진행함 | 단계는 되돌릴 수 없음, workflow를 삭제하고 새로 시작함 |
| Agent가 "OPENAI_API_KEY가 설정되지 않았습니다"라고 함 | 서버에 OpenAI key가 설정되지 않은 것임, 운영자에게 문의함 |
| 예측 실패 "representation mismatch" | 모델을 학습할 때와 서버의 representation 설정이 다른 것임, 운영자에게 문의함 |
| 화면이 예전 그대로임 | 브라우저 캐시임, Ctrl+F5로 새로고침 |
