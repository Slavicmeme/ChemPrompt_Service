## 0. 시작하기
1. 브라우저에서 `http://<서버 주소>:<포트>` 접속
2. **회원가입** 탭에서 username(영문/숫자 3자 이상)과 password(8자 이상)로 가입, 가입 즉시 로그인
3. 상단 메뉴에서 기능 선택: **예측 / Agent / Custom 학습 / 기록**, ADMIN 계정은 **Admin** 추가 표시

## 1. 기능별 사용법

### 1.1 예측
- 상단 **예측** 메뉴
- 순서
  1. property 카드 선택: **FreeSolv(수화 자유에너지) / ESOL(수용해도) / Lipo(친유성) / ClinTox(임상 독성)**
  2. SMILES 입력 (한 줄에 하나, 최대 100개)
  3. **예측 실행**
- Custom 모델 예측은 아래 "Custom 모델 사용" 목록에서 선택
  - 목록 대상: 내 모델(READY/SERVING)과 Admin이 승인한 공개 모델
- 결과 화면
  - 회귀: 예측 값과 단위, Model 1~5 평균, 모델 간 표준편차, 값 해석 설명
  - 분류(ClinTox): 항목별 확률, 판정(예: "1 · FDA 승인 약물"), 판정 기준 0.5
  - "모델별 결과 · 재현 정보"를 펼치면 Model 1~5 각각의 값과 모델 버전, descriptor 방식, 분할 방식, representation 확인 가능
- RDKit이 해석하지 못하는 SMILES는 그 행만 실패 표시, 나머지는 정상 예측

### 1.2 Agent
- 상단 **Agent** 메뉴, 자연어 질문에 답변 (예: "아스피린 CC(=O)Oc1ccccc1C(=O)O 수용해도 예측해줘")
- 예측 값은 Agent가 직접 만들지 않음, 항상 서비스의 예측 모델(Model 1~5)을 tool로 호출한 결과를 설명
- SMILES나 property가 빠져 있으면 먼저 되물음
- 답변은 Markdown(굵은 글씨, 목록, 표) 형식으로 표시
- tool 호출과 결과는 회색 상자로 표시, "상세"를 펼치면 원본 결과 확인 가능
- 왼쪽 목록에서 이전 대화 다시 열기 가능
- `.env`에 `OPENAI_API_KEY`가 없으면 "OPENAI_API_KEY가 설정되지 않았습니다" 안내 표시

### 1.3 Custom 학습
- 상단 **Custom 학습** 메뉴, 내 CSV 데이터로 ChemPrompt 모델(Model 1~5)을 학습하는 기능

#### CSV 준비
- 필수 열 2개: **SMILES 열**(분자 구조) + **Target 열**(예측할 숫자 값)
- 다른 열(ID, 이름 등)은 있어도 무방, 학습에는 미사용
- 최소 25행 이상, 파일 크기 50MB 이하
- 분류 데이터는 target이 0/1, 각 클래스 5개 이상 필요
- 예시 파일: `sample/hppb.csv` (HPPB, 혈장 단백질 결합률 %, 1,614개 분자, SMILES 열 이름은 `smile`)

#### 학습 순서 (10단계)
| 단계 | 하는 일 | 입력 |
|---|---|---|
| 1. Dataset Upload | CSV 업로드 | 이름, 파일 |
| 2. Column Mapping | SMILES 열과 Target 열을 하나씩 선택 | 자동 추천, 열 미리보기 제공 |
| 3. Validation | 결측·숫자 아닌 target·잘못된 SMILES 행 제거, 학습 가능 여부 확인 | 없음 |
| 4. Task Configuration | 회귀/분류 선택, 모델 이름 | 데이터에서 추론한 값이 기본 |
| 5. Descriptor Mode | FULL / FEATURE_SELECTION / GENETIC | 선택 |
| 6. Split Strategy | RANDOM(무작위) / SCAFFOLD(분자 골격 기준) | 선택 시 학습 자동 시작 |
| 7~10. 자동 | representation 생성 → Model 1~5 학습 → 평가 → 모델 등록 | 진행 상황 실시간 표시 |

- 2단계에서 SMILES가 아닌 열(예: ID 열)을 고르면 즉시 안내 메시지 표시, 다음 단계 진행 불가
- 단계는 순서대로만 진행, 앞 단계로 되돌리기 불가, 잘못 진행했으면 workflow 삭제 후 새로 시작
- 학습 완료 후 "모델별 검증 결과" 표 표시, 모델은 READY 상태로 **내 모델** 목록에 등록
- READY 모델은 본인이 바로 예측에 사용 가능, 다른 사용자에게 공개하려면 Admin 승인 필요

#### 학습 중단과 삭제
- **학습 중단**: 진행 중인 workflow 상세 화면의 "학습 중단" 또는 목록의 "중단"
  - 진행 중인 단계가 끝나는 시점(단계 사이, embedding 묶음 사이)에 정지, 보통 몇 초 이내
  - 중단된 workflow는 CANCELLED 상태, 이어서 진행 불가
- **Workflow 삭제**: 진행 중이 아닌 workflow의 "Workflow 삭제" / "삭제"
  - 함께 삭제되는 것: workflow 기록, 학습 기록, 그 workflow에 올린 데이터셋, embedding 캐시
  - 학습으로 만든 모델이 있으면 버튼 3개 중 선택
    - **취소**: 아무것도 삭제하지 않음 (Esc, 창 바깥 클릭도 동일)
    - **Workflow만 삭제 (모델 유지)**: 모델은 남아서 계속 예측에 사용 가능
    - **모델까지 모두 삭제**: 모델과 그 모델로 한 예측 기록까지 삭제
  - 학습 중인 workflow는 삭제 불가, 먼저 중단 필요
- **내 모델 삭제**: "내 모델" 목록의 "삭제"
  - 모델 파일과 그 모델로 한 예측 기록 함께 삭제
  - Admin이 승인한(SERVING) 모델은 삭제 불가, Admin에게 Archive 요청
- 삭제는 복구 불가

### 1.4 기록
- 상단 **기록** 메뉴, 내 예측 기록 목록 (최근 100건)
- 행을 클릭하면 아래에 결과 상세(모델별 결과, 재현 정보) 표시
- 경로 열의 WEB은 예측 화면, AGENT는 Agent 대화에서 한 예측

### 1.5 Admin (운영자)
- ADMIN 계정으로 로그인하면 상단 메뉴에 **Admin** 탭 표시 (`http://<서버 주소>:<포트>/#/admin`)
- 일반 사용자에게는 탭 미표시, 주소를 직접 입력해도 서버가 차단(403)
- 화면 구성과 가능한 작업
  | 영역 | 가능한 작업 |
  |---|---|
  | Representation | 현재 embedding 방식(mock / Aya)과 Aya 서비스 상태 확인 |
  | 현황 | 모델 상태별 개수, 사용자 수, 학습 작업 수 |
  | Model versions | 모든 모델(built-in + 사용자) 목록, **검증**, **승인·Serving**, **Archive**, **상세**(metadata, 파일 목록, seed 등) |
  | 모델 패키지 업로드 | 외부에서 학습한 모델 zip 업로드 → 자동 검증 |
  | Built-in 데이터 · 학습 | built-in property의 데이터 버전 등록, descriptor mode / split을 골라 5-fold 학습 시작 |
  | Training jobs | 모든 학습 작업 목록, 진행 중인 작업 **중단** |
  | Users | 가입한 사용자 목록 |
- Aya representation 서비스는 화면 없는 내부 API, 운영자 화면과 별개

## 2. 결과 해석

### Property 이름과 단위
| 코드 | 국문 이름 | 단위 | 해석 |
|---|---|---|---|
| FreeSolv | 수화 자유에너지 | kcal/mol | 음수일수록 물과 잘 어울림(친수성), 양수일수록 물을 싫어함(소수성), MoleculeNet 원본 `SAMPL.csv` 실험값 사용 (예: 에탄올 −5.0) |
| ESOL | 수용해도 | log(mol/L) | 클수록 물에 잘 녹음 (0 = 1 mol/L, −2 = 0.01 mol/L) |
| Lipo | 친유성 (지질 분배계수) | logD | pH 7.4 옥탄올/물 분배계수, 클수록 지방(세포막) 쪽으로 잘 분배 |
| ClinTox | 임상 독성 | 확률 (0~1) | 아래 두 항목을 각각 예/아니오로 분류 |

| ClinTox 항목 | 국문 이름 | 1이면 | 0이면 |
|---|---|---|---|
| FDA_APPROVED | FDA 승인 여부 | 미국 FDA 승인 약물 | 미승인 |
| CT_TOX | 임상시험 독성 | 독성 때문에 임상시험에서 실패 | 독성으로 인한 실패 없음 |

### 예측 값 읽는 법
- 예측 값은 Model 1~5의 평균
- **모델 간 표준편차**: 5개 모델의 예측이 갈리는 정도를 보여 주는 참고치, 클수록 예측이 불확실
- 분류는 Model 1~5 확률의 평균, 0.5 이상이면 1로 판정
- 예측 값과 오차(RMSE)는 모두 **target의 원래 단위**
- 학습 데이터와 많이 다른 분자는 범위 밖 값이 나올 수 있음 (예: 결합률 %인데 음수), 연구 참고용이며 실험 검증을 대체하지 않음

### 검증 성능이란
- 학습에 쓰지 않은 데이터로 모델을 시험한 점수
- 각 Model(1~5)은 데이터의 약 80%로 학습, 학습 때 보지 못한 나머지 20%로 예측해 실제 값과 비교
- Model 1~5는 서로 다른 20%로 시험, 화면의 값은 5개 결과의 평균 ± 표준편차
- "처음 보는 분자를 넣었을 때 이 정도로 맞힌다"는 기대치

| 지표 | 쓰는 곳 | 의미 | 좋은 값 |
|---|---|---|---|
| RMSE | 회귀 | 예측과 실제 값의 평균적인 오차 크기 (원래 단위) | 작을수록 좋음 |
| R² (결정계수) | 회귀 | 실제 값의 차이를 예측이 설명하는 정도 | 1에 가까울수록 좋음, 0이면 평균값으로 찍는 수준 |
| Pearson | 회귀 | 예측과 실제 값이 직선적으로 함께 움직이는 정도 | 1에 가까울수록 좋음 |
| Spearman | 회귀 | 분자들의 순위(어느 쪽이 더 큰지)를 맞히는 정도 | 1에 가까울수록 좋음 |
| ROC-AUC | 분류 | 1인 분자와 0인 분자를 구분하는 능력 | 1에 가까울수록 좋음, 0.5면 무작위 수준 |
| F1 / Accuracy | 분류 | 판정(0/1)이 맞은 정도 | 1에 가까울수록 좋음 |

- 개발용 설정(`REPRESENTATION_MODE=mock`)으로 학습한 모델의 성능 값은 실제 ChemPrompt(Aya) 성능과 무관, 실제 성능은 Aya 모드 학습으로 확인

## 3. 자주 묻는 질문

| 증상 / 질문 | 원인과 해결 |
|---|---|
| 운영자 화면 위치 | 같은 홈페이지에서 ADMIN 계정으로 로그인 → 상단 **Admin** 탭 |
| Custom 학습 2단계에서 "SMILES가 아닌 것 같습니다" | SMILES가 아닌 열 선택, 열 미리보기에서 "SMILES로 보임" 표시가 있는 열 선택 |
| Custom 학습 잘못 진행 | 단계 되돌리기 불가, workflow 삭제 후 새로 시작 |
| Agent가 "OPENAI_API_KEY가 설정되지 않았습니다" 안내 | 서버에 OpenAI key 미설정, 운영자에게 문의 |
| 예측 실패 "representation mismatch" | 모델 학습 때와 서버의 representation 설정 불일치, 운영자에게 문의 |
| 화면이 예전 그대로 | 브라우저 캐시, Ctrl+F5로 새로고침 |
